# Decision log

Decisions that code, tests and docs cite by ID, for example `(D23)` or `Accepted (D38, G45)`. D entries are decisions. G entries are work groups from the 2026-10-01 scan-remediation triage, cited for the rule their outcome set; their date is when that outcome was settled. IDs that nothing in the repository cites are left out, so the numbers have gaps.

To change a decision, add an entry that supersedes it and name the new entry in the old entry's status. `deployment/tests/test_decision_log.py` fails when a tracked file cites an ID that this log does not define.
